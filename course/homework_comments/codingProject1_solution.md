Coding Project 1 的批改必须先读图。学生报告中最关键的证据通常在四类图里：`d` 轴电流环扫频、`q` 轴电流环扫频、速度参考扫频、恒速负载转矩扫频。GPT 阅卷时应按下面顺序处理图片。

5. **判断是否真的扫了频。** 时间域图中频率应逐段变化，或 Bode/summary 图中应有多个频点。若只有一个正弦频率，最多算单频响应，不能算完整扫频。
6. **对 `d` 轴电流扫频要看速度是否基本不变。** 在基本 PMSM 设定下，`d` 轴电流主要反映电气动态，通常不应产生明显平均转矩。若 `d` 轴扫频导致速度剧烈变化，学生需要解释耦合、反电势或实验设置，否则不能说测到了纯电流环。

9. **对负载转矩扫频要确认速度命令恒定。** 负载扫频应保持 `cmd_rpm` 不变，对 `ACM.TLoad` 注入正弦扰动。若学生同时扫速度参考和负载，就不能直接解释为单独的抗扰通道。

11. **看趋势，不只看截图是否漂亮。** 正确图像应体现低频跟踪较好、高频幅值衰减和相位滞后增加；负载抗扰图应体现扰动频率升高后速度纹波更难抑制。

# 一、项目核心概念

扫频是在某个工作点附近注入正弦信号，并观察输出如何随频率变化。因此测到的不是“电机的一个固定频率响应”，而是某条具体输入输出通道：

$$
G(j\omega)=\frac{Y(j\omega)}{U(j\omega)}.
$$

在多闭环 FOC 系统中，扫频结果由以下因素决定：

- 输入信号注入在速度参考、电流参考还是负载转矩。
- 输出观测的是速度、电流、速度误差还是负载扰动响应。
- 速度环是否闭合，电流环是否闭合。
- 转子是否允许自由加减速。
- 电流环带宽是否足够高，速度环带宽是否按目标整定。

最重要的批改原则：学生必须说清楚每张图的输入、输出、注入点和观测点。只放图不解释，不能得高分。

if CTRL.bool_apply_sweeping_frequency_excitation == True:
    if CTRL.timebase > CTRL.CMD_SPEED_SINE_END_TIME:

        CTRL.cmd_idq[1] = 0.0
    else:
        CTRL.cmd_rpm = CTRL.CMD_SPEED_SINE_RPM * np.sin(

            * (CTRL.timebase - CTRL.CMD_SPEED_SINE_LAST_END_TIME)

## 2.3 `tuner.py` 中的整定公式

电流环 PI：

$$
K_{p,i}=2\pi L\,BW_c,
\qquad
K_{i,i}=\frac{R}{L}.
$$

速度环 PI：

$$
K_{i,\omega}=\frac{\omega_{ci}}{\delta^2},
\qquad
K_{p,\omega}=
\frac{J_s/n_{pp}}{1.5\,n_{pp}K_A}\,
\delta K_{i,\omega}.
$$

其中 `FOC_desired_VLBW_HZ` 是目标速度环带宽，`FOC_delta` 类似阻尼或带宽分离参数。若要重新整定，通常应把 `CL_SERIES_KP/KI` 和 `VL_SERIES_KP/KI` 置为 `None`，让 `tunner_wrapper(d)` 重新计算。

# 三、Q1 到 Q7 参考答案

## Q1：扫频到底在测什么？

扫频测的是某条输入输出路径的频率响应。必须明确：

- 输入是什么：速度参考、电流参考或负载转矩。
- 输出是什么：速度、电流、速度误差或其他观测量。
- 信号在哪里注入：速度环输入、电流环输入或机械扰动入口。
- 哪些动态被包含：电流环、速度环、机械系统、反电势和负载扰动。

正确表述示例：

$$
G_{v2v}(j\omega)=\frac{\omega_m(j\omega)}{\omega_m^\ast(j\omega)}
$$

这是速度参考到实际速度的闭环跟踪通道。

$$
G_{i2i}(j\omega)=\frac{i_q(j\omega)}{i_q^\ast(j\omega)}
$$

这是电流参考到实际电流的电流环通道。

$$
G_{T2v}(j\omega)=\frac{\omega_m(j\omega)}{T_L(j\omega)}
$$

这是负载转矩到速度的闭环抗扰通道。

常见错误：只说“扫电机的频率响应”，但没有说明输入输出路径。

## Q2：速度环扫频和电流环扫频分别在测什么？

速度环扫频通常是把正弦信号加到速度参考 `cmd_rpm`，观察实际速度 `omega_r_mech` 如何跟踪。因此它测的是闭环速度跟踪：

$$
\frac{\omega_m}{\omega_m^\ast}.
$$

电流环扫频是把正弦信号加到 `cmd_idq[0]` 或 `cmd_idq[1]`，观察 `i_d` 或 `i_q`。如果机械速度固定，比较接近纯电流环：

$$
\frac{i_d}{i_d^\ast}, \qquad \frac{i_q}{i_q^\ast}.
$$

如果扫 `q` 轴电流且转子可以自由运动，则 `i_q` 会产生转矩，进一步改变速度和反电势。此时测到的不再是纯电流环，而是电流环和机械系统的耦合响应。

负载转矩扫频不是参考跟踪，而是抗扰：

$$
\frac{\omega_m}{T_L}.
$$

它和速度参考扫频共享同一个闭环系统的一部分，但注入点不同，所以不是同一条传递函数。

## Q3：扫电流环时，转速应变化还是保持不变？

如果目标是测“纯电流环”，转速最好保持固定或变化很小。原因是电机电压方程包含速度相关反电势和交叉耦合项，速度变化会污染电流环测量。

`d` 轴扫频：

- 在基本 PMSM 设定下，`d` 轴电流通常不直接产生平均转矩。
- 因此 `d` 轴扫频更适合观察电气动态。
- 图中速度应基本不变，或学生应解释为什么出现速度变化。

`q` 轴扫频：

- `q` 轴电流产生电磁转矩：

$$
T_e=\frac{3}{2}n_{pp}K_A i_q.
$$

- 如果转子自由运动，`q` 轴扫频必然可能引起速度波动。
- 此时扫频结果包含电流环、机械惯量、负载和速度相关反电势。

所以满分答案应分开讨论 `d` 轴和 `q` 轴，而不是简单说“电流环扫频时速度不应该变”。

## Q4：为什么速度指令扫频时，`i_q` 幅值通常随频率升高而变大？

机械方程为：

$$
J\frac{d\omega_m}{dt}=T_e-T_L,
\qquad
T_e=\frac{3}{2}n_{pp}K_A i_q.
$$

若速度参考为：

$$
\omega_m^\ast(t)=A\sin(2\pi f t),
$$

则加速度参考为：

$$
\frac{d\omega_m^\ast}{dt}=2\pi f A\cos(2\pi f t).
$$

在速度幅值 `A` 固定时，频率 `f` 越高，需要的加速度幅值越大。更大的加速度需要更大的电磁转矩，更大的电磁转矩需要更大的 `i_q`。因此速度扫频中常见现象是：频率升高时，速度跟踪逐渐变差，相位滞后增加，同时 `i_q` 幅值先增大，之后可能因电流或电压限幅而不能继续增大。

常见错误：只说“控制器努力跟踪所以电流变大”，但没有从机械方程解释。

## Q5：恒速负载转矩扫频与速度参考扫频有什么联系和区别？

两者都经过速度闭环和电流内环，因此闭环分母可能相同或相近。但它们的注入点不同：

- 速度参考扫频输入在参考端，是跟踪问题。
- 负载转矩扫频输入在机械方程扰动端，是抗扰问题。

简化框图下可写成：

$$
\frac{\omega_m}{\omega_m^\ast}
\sim
\frac{C_vG_iG_m}{1+C_vG_iG_m},
$$

$$
\frac{\omega_m}{T_L}
\sim
-
\frac{G_d}{1+C_vG_iG_m}.
$$

其中 `C_v` 是速度控制器，`G_i` 是电流环，`G_m` 是机械对象。两者共享 `1+C_vG_iG_m` 这样的闭环抑制项，但分子和注入位置不同，所以幅值、相位和物理意义不同。

满分答案应说明：速度参考扫频看的是系统能否跟随命令；负载转矩扫频看的是系统能否抑制外部扰动。

## Q6：电流环如何影响负载转矩扫频结果？

从速度环角度看，电流环是转矩执行器。速度 PI 输出 `i_q^*`，但只有电流环把 `i_q^*` 变成实际 `i_q` 后，电机才产生电磁转矩。

如果电流环带宽高：

- 实际 `i_q` 更快跟随 `i_q^*`。
- 速度环可以更快生成补偿转矩。
- 负载扰动造成的速度纹波更小，相位滞后更少。

如果电流环带宽低：

- `i_q` 对命令有额外滞后和幅值衰减。
- 速度环看到的是一个更慢的转矩执行器。
- 负载扫频在较低频率就会出现更明显速度波动和相位滞后。

因此负载转矩扫频不是只测机械惯量，也会受到电流内环带宽影响。

## Q7：如何改变带宽？哪些参数重要？为什么？

主要参数：

- `FOC_desired_VLBW_HZ`：目标速度环闭环带宽。
- `FOC_delta`：影响速度环阻尼、带宽分离和响应保守程度。
- `CL_SERIES_KP/KI`：电流环 PI。
- `VL_SERIES_KP/KI`：速度环 PI。

若 `CL_SERIES_KP` 等为 `None`，`Simulation_Benchmark` 会调用 `tuner.tunner_wrapper(d)` 自动整定。电流环带宽由

$$
K_{p,i}=2\pi L\,BW_c
$$

直接影响。速度环由

$$
K_{i,\omega}=\frac{\omega_{ci}}{\delta^2},
\qquad
K_{p,\omega}=
\frac{J_s/n_{pp}}{1.5\,n_{pp}K_A}\delta K_{i,\omega}
$$

决定。

预期实验结论：

- 提高速度环带宽通常改善低频跟踪和抗扰速度。
- 过高带宽会带来更大电流需求、相位裕度下降、振荡、限幅或噪声放大。
- 增大 `FOC_delta` 通常让响应更保守，超调和振荡减小，但跟踪和抗扰变慢。
- 电流环带宽必须高于速度环需求，否则速度环设计目标无法实现。

> `d` 轴扫频主要测电流参考到电流反馈的电气闭环。因为 `d` 轴电流在基本 PMSM 中不直接产生平均转矩，所以机械动态污染较小。

## 4.2 `q` 轴电流环扫频图

应有的实验设置：

- 输入：`i_q^*` 或 `CTRL.cmd_idq[1]` 的正弦扫频。
- 输出：实际 `i_q`。
- 还应观察速度或转矩，以判断机械耦合。

图中应观察：

- 低频 `i_q` 跟踪较好，高频出现滞后和衰减。
- 若转子自由运动，速度会随 `i_q` 扭矩波动。
- 若速度被固定或速度变化很小，结果更接近纯电流环。

可接受结论：

> `q` 轴电流扫频既可以用于测电流环，也可能激发机械系统。关键取决于转子是否允许自由加速。如果速度变化明显，就不能把结果解释成纯电流环。

常见扣分：

- 把 `q` 轴电流扫频无条件说成纯电流环。
- 没有讨论 `q` 轴电流产生转矩。
- 没有说明速度是否固定。

## 4.3 速度环扫频图

应有的实验设置：

- 输入：速度参考 `cmd_rpm` 或 `omega_m^*`。
- 输出：实际速度 `omega_m` 或 `CTRL.omega_r_mech`。
- 速度环闭合。
- 电流环正常工作。

图中应观察：

- 低频时实际速度能跟随速度参考。
- 频率升高后，速度幅值衰减，相位滞后增加。
- `i_q` 幅值通常随频率升高而增大，直到受限幅或带宽限制。

可接受结论：

> 速度扫频测的是速度参考到实际速度的闭环跟踪通道。`i_q` 不是输入输出路径的最终输出，但它揭示了为了产生加速度所需的转矩电流。

常见扣分：

- 只画 `cmd_rpm`，没有实际速度。
- 没有解释高频下滞后和衰减。
- 没有回答 `i_q` 幅值为什么增加。

## 4.4 恒速负载转矩扫频图

应有的实验设置：

- 输入：`ACM.TLoad` 的正弦扰动。
- 速度参考：保持常值。
- 输出：实际速度、速度误差、`i_q` 或抗扰相关量。

图中应观察：

- 负载扰动引起速度纹波。
- 速度环通过改变 `i_q` 抵消负载扰动。
- 低频负载扰动更容易被抑制，高频负载扰动会带来更大相位滞后和残余速度纹波。

可接受结论：

> 负载转矩扫频测的是扰动到速度的闭环抗扰通道，不是速度命令跟踪通道。它与速度参考扫频相关，但注入点不同，传递函数不同。

常见扣分：

- 速度参考也在扫频，导致无法单独说明负载扰动。
- 只画 `ACM.TLoad`，没有速度响应。
- 把负载扫频和速度参考扫频说成同一件事。

# 五、建议的实验和代码思路

## 5.1 四种实验模式

学生可以用不同实现方式完成，但逻辑应类似：

```python
mode = "speed_sweep"      # speed_sweep, id_sweep, iq_sweep, load_sweep
phase = 2 * np.pi * f * (CTRL.timebase - t0)

if mode == "speed_sweep":
    CTRL.cmd_rpm = speed_amp_rpm * np.sin(phase)
    ACM.TLoad = 0.0

elif mode == "id_sweep":
    CTRL.cmd_rpm = constant_speed_rpm
    CTRL.cmd_idq[0] = id_amp * np.sin(phase)

elif mode == "iq_sweep":
    CTRL.cmd_rpm = constant_speed_rpm
    CTRL.cmd_idq[1] = iq_amp * np.sin(phase)

elif mode == "load_sweep":
    CTRL.cmd_rpm = constant_speed_rpm
    ACM.TLoad = load_amp_nm * np.sin(phase)
```

注意：如果速度环会覆盖 `cmd_idq[1]`，学生必须处理这一点。例如在电流环扫频实验中关闭速度环，或明确在哪个位置注入 `cmd_idq[1]`，避免被速度 PI 输出覆盖。

## 5.2 从每个扫频段提取幅值和相位

报告至少应有一个小函数或脚本，用于从每个频率段提取幅值、峰峰值或相位。参考思路：

```python
import numpy as np

def sine_fit_amp_phase(t, y, freq_hz):
    y = y - np.mean(y)
    w = 2 * np.pi * freq_hz
    s = np.sin(w * t)
    c = np.cos(w * t)
    a = 2.0 * np.mean(y * s)
    b = 2.0 * np.mean(y * c)
    amp = np.sqrt(a * a + b * b)
    phase_rad = np.arctan2(b, a)
    return amp, phase_rad

def gain_phase(t, u, y, freq_hz):
    amp_u, ph_u = sine_fit_amp_phase(t, u, freq_hz)
    amp_y, ph_y = sine_fit_amp_phase(t, y, freq_hz)
    gain = amp_y / max(amp_u, 1e-12)
    phase = ph_y - ph_u
    return gain, phase
```

更完整的做法应跳过每段开始的暂态，只使用该频率段后半段或最后若干周期估计幅值和相位。

- 频率 `f`。

- 输出幅值。

# 九、常见错误和批改建议

1. **只提交默认波形。** 如果没有区分四种扫频路径，最多给基础运行分和少量图像分。
2. **速度参考和电流参考同时扫。** 如果学生没有解释如何分离输入，扣实验设置分。若仍能从图中分析部分现象，可给少量分析分。
3. **把 `q` 轴电流扫频说成纯电流环。** 若图中速度明显变化，应扣概念分。
4. **负载扫频没有保持速度参考恒定。** 不能作为标准抗扰实验。
5. **只画时间域波形，不整理频率响应。** 可给实验完成分，但 summary/Bode 和分析分应降低。
6. **没有单位或图例。** GPT 无法确认输入输出，图像证据分应扣。
7. **只说高带宽更好。** 必须同时说明代价：电流需求、限幅、噪声、相位裕度和振荡风险。
8. **没有提到电流环对速度环的作用。** Q6 应扣分，因为负载抗扰依赖 `i_q` 执行转矩。

# 十、核心结论

Coding Project 1 的核心答案是：

扫频测到的是某条具体输入输出通道的频率响应。速度参考扫频测闭环跟踪，电流参考扫频测电流环或电流加机械耦合，恒速负载转矩扫频测闭环抗扰。`d` 轴电流更适合观察电气动态，`q` 轴电流会产生转矩并可能激发机械系统。速度扫频中 `i_q` 随频率增大，是因为固定速度幅值下需要的加速度与频率成正比。带宽提高通常改善低频跟踪和抗扰，但会牺牲稳定裕度、增加电流需求并放大噪声或限幅问题。

GPT 批改时必须先读图片，确认每张图的输入、输出、注入点、坐标轴、单位和趋势，再根据文字解释给分。只有图没有解释，或只有解释没有可读图像证据，都不能给满分。
