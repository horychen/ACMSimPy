Lecture 3 / 第三讲

Motion Control: Observer, Feedforward & the Three-Way Tradeoff

运动控制：观测器、前馈补偿与跟踪-抗扰-噪声的三方权衡

Related: Coding Projects 2 & 3 Topics: ESO, GPIO, ADRC, Feedforward, Noise
Overview / 总述

为什么需要超越 PI？/ Why Go Beyond PI?

在 Lecture 2 中我们建立了统一电机模型。在 Coding Project 1-2 中你已经体验了 PI 调参和前馈解耦。但 PI 只能"被动"地用误差去纠正——它不知道扰动是什么，只能等误差出现后再反应。

本讲介绍一种"主动"策略：用观测器估计扰动，然后前馈补偿。这就是 Active Disturbance Rejection Control (ADRC) 的核心思想。我们将从三个维度评价控制系统：

  1. Command Tracking（指令跟踪）——跟踪速度给定有多快？
  2. Disturbance Rejection（扰动抑制）——抗负载扰动有多强？
  3. Noise Attenuation（噪声抑制）——对测量噪声有多敏感？

这三者之间存在根本性的权衡：不可能同时最优。本讲将用传递函数语言精确描述这一权衡。

6.1 Command Tracking / 指令跟踪

从速度参考到速度输出 / Reference to Output

对于速度环，采用线性反馈控制律 $\dot{e}_s = -k_{ps} e_s$，其中 $e_s = \Omega^* - \hat{\Omega}$ 是速度跟踪误差，可以推导出转矩参考：

$$T_e^* = \frac{\dot{\Omega}^* + k_{ps}(\Omega^* - \hat{\Omega}) - \hat{d}_{to}}{b_n}$$
(1) — 控制律

其中 $b_n = 1/J_n$ 是标称控制增益，$\hat{\Omega}$ 和 $\hat{d}_{to}$ 分别是观测器估计的速度和总扰动。

闭环系统的输出可以表示为：

$$\Omega(s) = \underbrace{\Phi_r(s)}_{\text{tracking}} \Omega^*(s) + \underbrace{\Phi_d(s)}_{\text{disturbance}} d_n(s) + \underbrace{\Phi_n(s)}_{\text{noise}} (-s\delta_p(s))$$
(2) — 三通道分解
关键结论：当 $k_b = J/J_n = 1$（惯量匹配）时，系统具有完美的跟踪性能 $\Phi_r(s) = 1$。任何惯量失配 ($k_b \neq 1$) 都会导致跟踪性能退化。

跟踪性能指标

  • 上升时间 $t_r$：由反馈增益 $k_{ps}$ 决定，$k_{ps}$ 越大越快
  • 超调量：与 $k_b$ 密切相关——$k_b > 1$ 会导致超调和振荡
  • 稳态误差：理论上为零（前提：观测器估计收敛）
6.2 Disturbance Rejection / 扰动抑制

扰动传递函数 / Disturbance-to-Output Path

扰动传递函数描述了外部扰动（如负载转矩）到速度输出的关系：

$$\Phi_d(s) = \frac{\Omega(s)}{d_n(s)} = \frac{k_b G_3(s)}{\Delta_n(s+k_{ps}) + (k_b - 1)sG_3(s)}$$
(3) — 扰动传递函数

其中 $\Delta_n = (s + \omega_{ob})^n$ 是观测器的特征多项式（$n=3$ 或 $4$），$G_3(s)$ 由观测器结构决定。

3 阶 vs 4 阶观测器的扰动抑制能力

内模原理 (Internal Model Principle)：要以零稳态误差跟踪某类信号，控制器/观测器的内部模型必须包含该信号的动态特征。
  • 3 阶观测器：内部模型假设 $\dot{d}_{to} = 0$（恒定扰动）→ 能无差跟踪阶跃扰动
  • 4 阶观测器：内部模型假设 $\ddot{d}_{to} = 0$（斜坡扰动）→ 能无差跟踪阶跃和斜坡扰动

低频 vs 高频扰动抑制

从 Bode 图分析：

  • 低频扰动抑制能力主要由观测器的扰动估计性能决定。高阶观测器在低频具有更陡的衰减斜率（更好的抑制）
  • 高频扰动抑制能力主要由反馈增益 $k_{ps}$ 决定，与观测器阶数关系不大
$$\text{3rd-order: low-freq slope} = +20\ \text{dB/dec (ESO\_1)},\quad \text{4th-order: up to } +60\ \text{dB/dec (ESO\_8)}$$
6.2b System Type / 系统型别

换一个视角：从负载转矩看系统型别 / A Different Viewpoint: System Type from the Load's Perspective

经典控制理论中，系统的"型别"（system type）定义为开环传递函数中 $s=0$ 处的积分器个数。Type I 系统能无差跟踪阶跃，Type II 能无差跟踪斜坡，Type III 能无差跟踪抛物线。

现在我们换一个视角：把负载转矩 $T_L$ 当作"输入"，转速 $\Omega$ 当作"输出"，来分析这条扰动通道的型别。

核心洞察：ESO 是级联积分器

观测器估计扰动的过程，本质上是在反馈通路中构造积分器链：

$$\underbrace{\hat{d}_{to} = \frac{\ell_3}{s} e_\theta}_{\text{1 个积分器}} \quad\Longrightarrow\quad \text{Type I（对扰动）} \quad\Longrightarrow\quad \text{零稳态误差 for 阶跃 } T_L$$
$$\underbrace{\hat{p}_{to} = \frac{\ell_4}{s} e_\theta,\quad \hat{d}_{to} = \frac{1}{s}\hat{p}_{to} + \frac{\ell_3}{s} e_\theta}_{\text{2 个级联积分器}} \quad\Longrightarrow\quad \text{Type II（对扰动）} \quad\Longrightarrow\quad \text{零稳态误差 for 斜坡 } T_L$$
统一理解：观测器每多扩展一阶状态，就在扰动抑制通道中多串联一个积分器，系统型别提升一级。

观测器阶数 扰动通道积分器数 系统型别 能无差跟踪的扰动
3 阶 ESO 1 Type I 阶跃 $T_L$（恒定负载）
4 阶 ESO 2 Type II 斜坡 $T_L$（线性增加负载）
5 阶 ESO 3 Type III 抛物线 $T_L$（加速度变化的负载）

为什么这个视角很有用？

传统讲 ADRC/ESO 时，通常从"内模原理"解释——观测器内部模型必须包含扰动的动态特征。这是正确的，但不够直觉。

系统型别的视角更直接：你只需要数一数，从负载转矩到速度输出的闭环通路中有几个积分器，就能立刻知道系统能抗什么形状的扰动。这和你在本科自动控制原理中学的系统型别判据完全一样——只不过"输入"从参考指令换成了扰动。

与参考跟踪的类比：
在参考跟踪通道中，PI 控制器提供了一个积分器（$K_i/s$），使得系统对阶跃参考是 Type I——零稳态误差。如果你再加一个积分器（PII 控制器），系统对斜坡参考也是零稳态误差。

在扰动通道中，ESO 的扩展状态扮演了同样的角色：每多估计一阶扰动的导数，就等价于在扰动通道中多了一个积分器。3 阶 ESO 的一个扩展状态 $\hat{d}_{to}$ 对应一个积分器（Type I）；4 阶 ESO 的两个扩展状态 $\hat{d}_{to}, \hat{p}_{to}$ 对应两个级联积分器（Type II）。

从传递函数验证

以 $k_b = 1$ 为例，扰动传递函数 $\Phi_d(s)$ 在 $s \to 0$ 时的行为：

$$\text{3 阶 ESO:}\quad \Phi_d(s) \sim \frac{s}{\omega_{ob}(s + k_{ps})} \quad\text{as } s\to 0 \quad\Longrightarrow\quad \Phi_d(0) = 0$$
对阶跃扰动：稳态输出为零 (Type I)
$$\text{4 阶 ESO:}\quad \Phi_d(s) \sim \frac{s^2}{\omega_{ob}^2(s + k_{ps})} \quad\text{as } s\to 0 \quad\Longrightarrow\quad s\Phi_d(s)\big|_{s=0} = 0$$
对斜坡扰动：稳态输出为零 (Type II)

$\Phi_d(s)$ 在 $s=0$ 处的零点个数，正好等于观测器扩展状态的阶数。这就是型别的传递函数定义。

思考题
如果我们不用 ESO，而是在速度 PI 控制器中再串联一个积分器（变成 PII），能不能也实现 Type II 的扰动抑制？为什么实际中不这么做？
提示：考虑相位裕度和稳定性。积分器加在反馈控制器中会同时影响所有三条通道（跟踪、扰动、噪声），而 ESO 的积分器只加在扰动估计通道中。
6.3 Noise Attenuation / 噪声抑制

高阶观测器的代价 / The Cost of Higher Order

噪声传递函数为：

$$\Phi_n(s) = 1 - s\Phi_d(s)$$
(4) — 噪声与扰动的互补关系
核心权衡：$\Phi_n(s)$ 和 $s\Phi_d(s)$ 满足互补关系——改善扰动抑制必然恶化噪声抑制，反之亦然。这是一个基本约束，无法通过调参绕过。

实际影响

  • 更好的低频扰动抑制（高阶观测器）→ 更差的高频噪声抑制
  • 3 阶 ESO\_1：高频噪声衰减 $-60$ dB/dec（最佳噪声抑制）
  • 4 阶 ESO\_8：高频噪声衰减 $-40$ dB/dec（最佳扰动抑制，但噪声更大）
  • 4 阶 ESO\_4：折中方案，$-60$ dB/dec 噪声衰减 + $+40$ dB/dec 扰动抑制

速度测量噪声不是白噪声——它是由编码器量化误差导致的有色噪声，其功率谱密度随转速和频率变化。因此，观测器带宽 $\omega_{ob}$ 的选择不能只看理论 Bode 图，还要考虑实际噪声特性。

6.4 Two-Degree-Of-Freedom PI / 二自由度 PI

分离跟踪与抗扰 / Separating Tracking from Rejection

标准 PI 控制器只有一个自由度——$K_p$ 和 $K_i$ 同时影响跟踪和抗扰。二自由度 (2DOF) 控制器将二者分离：

$$T_e^* = \underbrace{C_r(s) \cdot \Omega^*}_{\text{tracking path}} - \underbrace{C_y(s) \cdot \hat{\Omega}}_{\text{feedback path}} - \underbrace{\frac{\hat{d}_{to}}{b_n}}_{\text{feedforward}}$$

其中 $C_r(s)$ 是参考滤波器（整形跟踪响应），$C_y(s)$ 是反馈控制器（决定抗扰和鲁棒性）。

与 ADRC 的联系：ADRC 本质上就是一个 2DOF 控制器：
  • ESO/GPIO 提供 $\hat{\Omega}$ 和 $\hat{d}_{to}$
  • 反馈增益 $k_{ps}$ 对应 $C_y(s)$
  • 前馈 $\hat{d}_{to}/b_n$ 提供扰动补偿
  • 可以独立调节跟踪带宽（通过参考滤波器）和抗扰带宽（通过观测器带宽）

从 PI 到 PI + 前馈

回忆 Coding Project 2 中的速度环 PI 控制器：

$$i_q^* = K_p(\omega^* - \hat{\omega}) + K_i \int (\omega^* - \hat{\omega}) dt$$

加入扰动前馈后：

$$i_q^* = \underbrace{K_p(\omega^* - \hat{\omega}) + K_i \int (\omega^* - \hat{\omega}) dt}_{\text{PI feedback}} + \underbrace{\frac{\hat{d}_{to}}{1.5\, n_{pp}\, K_A}}_{\text{disturbance feedforward}}$$

前馈项直接补偿扰动，PI 只需处理残余误差。这就是 Coding Project 3 中你要实现的内容。

6.5 Observer Order & Gain Design / 观测器阶数与增益设计

从 ESO 到 GPI Observer / From ESO to GPIO

统一的观测器框架

所有观测器都可以写成如下形式，区别仅在于扩展状态的阶数：

$$\begin{aligned} \dot{\hat{\theta}}_d &= \ell_1 e_\theta + \hat{\omega}_r \\ \dot{\hat{\omega}}_r &= \ell_2 e_\theta + (T_{em} + \hat{d}_{to}) \frac{n_{pp}}{J_s} \\ \dot{\hat{d}}_{to} &= \ell_3 e_\theta + \hat{p}_{to} \\ \dot{\hat{p}}_{to} &= \ell_4 e_\theta + \hat{q}_{to} \\ &\vdots \end{aligned}$$
通用 GPI 观测器结构

增益配置（极点配置法）

将所有观测器极点配置在 $s = -\omega_{ob}$：

$$\text{3rd-order:}\quad \ell_1 = 3\omega_{ob},\ \ell_2 = 3\omega_{ob}^2,\ \ell_3 = \omega_{ob}^3 \frac{J_s}{n_{pp}},\ \ell_4 = 0$$
$$\text{4th-order:}\quad \ell_1 = 4\omega_{ob},\ \ell_2 = 6\omega_{ob}^2,\ \ell_3 = 4\omega_{ob}^3 \frac{J_s}{n_{pp}},\ \ell_4 = \omega_{ob}^4$$

$\omega_{ob}$ 的选择

观测器带宽 $\omega_{ob}$ 是最关键的调参：

  • $\omega_{ob}$ 太小 → 估计收敛慢，扰动跟踪滞后
  • $\omega_{ob}$ 太大 → 放大测量噪声，可能导致不稳定
  • 高阶观测器需要更小的 $\omega_{ob}$（因为噪声放大更严重）
经验法则：$\omega_{ob}$ 通常取速度环带宽的 3-10 倍。对于 4 阶观测器，可能需要比 3 阶减小 30-50%。实际中需要在仿真或实验中找到最佳折中。
6.6 Robustness to Inertia Mismatch / 惯量失配鲁棒性

$k_b = J/J_n$ 对系统的影响 / Effect of Control Gain Ratio

定义控制增益比 $k_b = b_n/b = J/J_n$，即实际惯量与标称惯量之比。从闭环传递函数可知：

$$\Phi_r(s) = \frac{\Delta_n(s+k_{ps})}{\Delta_n(s+k_{ps}) + (k_b - 1)sG_3(s)}$$
(5) — 跟踪传递函数
  • $k_b = 1$：完美跟踪，$\Phi_r = 1$
  • $k_b > 1$（实际惯量大于标称）：超调、振荡，但噪声抑制更好
  • $k_b < 1$（实际惯量小于标称）：无超调，但噪声抑制变差
重要结论：低频扰动抑制能力越强的系统（如 4th-order ESO\_8），对 $k_b$ 变化越敏感。系统的稳定裕度更小。
例如：ESO\_1 在 $k_b > 0.258$ 时稳定，ESO\_4 在 $k_b > 0.233$ 时稳定，而 ESO\_8 在 $k_b < 2.94$ 时稳定。

实际中，惯量失配来源于：

  • 负载惯量变化（如机器人手臂不同姿态）
  • 标称惯量标定误差
  • 通常先在控制器中使用较小的 $J_n$（即 $k_b > 1$），因为 $k_b > 1$ 有利于噪声抑制
Summary / 总结

三方权衡的全景图 / The Complete Picture

核心结论
  1. 闭环系统的性能由三条传递函数决定：跟踪 $\Phi_r$、扰动 $\Phi_d$、噪声 $\Phi_n$
  2. $\Phi_n(s) = 1 - s\Phi_d(s)$——扰动抑制和噪声抑制是互补的，不可兼得
  3. 高阶观测器（GPIO）通过扩展内部模型来提升低频扰动抑制（如跟踪斜坡负载），但代价是高频噪声放大
  4. 观测器带宽 $\omega_{ob}$ 是最关键的设计参数——决定了扰动估计速度与噪声水平的权衡
  5. 惯量失配 $k_b \neq 1$ 同时影响跟踪、扰动、噪声三个通道。低频抗扰能力越强的系统对 $k_b$ 越敏感
  6. 2DOF 控制结构（PI + 前馈）可以分离跟踪设计和抗扰设计，提供更大的调参自由度

在 Coding Project 3 中，你将亲手实现这些概念：启用 4 阶观测器、接入前馈补偿、用斜坡负载证明高阶观测器的优势，并通过调节 $\omega_{ob}$ 体会噪声-抗扰的权衡。
